### Summary

Shared peach backdrop behind every screen; prettier formatting across seller features.

### User-Facing Changes

- Every screen now has the soft peach corner background, drawn once by each app's root layout through the new Backdrop component.
- Auth and tab navigators use transparent content with fade animation.
- Screens, stacks and tabs no longer paint their own background so the backdrop shows through everywhere; cards, tab bars and action bars stay opaque.

### Testing Scope

- Sign-in, forgot-password and reset-password screens in light and dark theme: fields, focus/error states, button label legibility.

- Confirm the soft peach corner background shows through on every screen in both themes.
