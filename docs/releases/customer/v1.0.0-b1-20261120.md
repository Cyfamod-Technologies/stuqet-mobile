### Summary

Adds the Stuqet design system: Urbanist typography, light and dark colour tokens, a restyled UI kit and new auth components.

### User-Facing Changes

- Stuqet Customer now uses the Urbanist font, off-white screens with white shadowed fields, and orange pill buttons with white labels.
- Inputs show an orange focus border, red error state, green verified check and a muted locked state.
- Checkboxes are larger with rounded corners and an orange glow when checked.
- Sign-in, forgot-password and reset-password screens were rebuilt on the new design: round back button, 6-box reset-code entry, an inline "code sent" notice, and a new "Password updated" confirmation screen.
- The login screen shows Google and Apple buttons (tapping them shows a "coming soon" message until OAuth is available).
- The welcome screen has new copy and the soft corner artwork.
- Every screen now has the soft peach corner background.
- Light and dark colour palettes were redefined around the Stuqet orange (`#EB6C1A`).

### Testing Scope

- Full forgot-password flow: request code, enter code and new password, "Password updated" screen, sign in. Reset code length is assumed to be 6 digits.
- Sign-in, forgot-password and reset-password screens in light and dark theme: fields, focus/error states, button label legibility.
- Settings theme toggle switches every screen without un-themed (white or black) regions.
- Text renders in Urbanist on both iOS and Android (no fallback system font, bold weights correct).
- Select dropdown, segmented control, badges and checkbox look correct in both themes.

### Known Issues

- Google and Apple sign-in are not functional yet; the buttons only show a "coming soon" message.
- Google and Apple buttons use the Ionicons glyphs, not the official brand artwork.
